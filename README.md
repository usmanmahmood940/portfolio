# Usman Mahmood — Portfolio

Personal portfolio site for [Usman Mahmood](https://www.linkedin.com/in/usmanmahmood940) (Android & Flutter engineer).

## Local preview

```bash
python3 -m http.server 8765 --directory .
```

Open http://127.0.0.1:8765/

## Structure

- `index.html` — single-page site
- `css/styles.css` — styles
- `js/main.js` — nav, filters, mailto form
- `assets/` — favicon + resume PDF

Static only — no build step.
